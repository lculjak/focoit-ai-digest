## Design decisions

- **Extension repo changed:** `githubnext/gh-aw` → `github/gh-aw` (migration completed by the
  gh-aw team; existing installs auto-upgrade to v0.85.4 on this machine).
- **Auth model simplified (June 2026):** `engine: copilot` now uses `copilot-requests: write` on
  the built-in `GITHUB_TOKEN`. The `COPILOT_GITHUB_TOKEN` PAT approach is deprecated. FAD-003
  acceptance criteria updated accordingly — no secret to create.
- **`max-ai-credits: 60` was dangerously low.** Default is 1000; an agentic digest run that fetches
  13 feeds, curates 15 stories, and generates a full HTML page will realistically consume 200–400
  AIC. Set to 500 as a conservative first-run calibration cap (FAD-007 will tune after real data).
- **Schedule syntax:** gh-aw compiler rejects `MON` in cron expressions; switched to the fuzzy
  `weekly on monday around 11:00` form which also eliminates the load-spike compiler warning.
- **`base` → `base-branch`:** schema changed in a recent gh-aw release; `base` is now only valid
  under agent-session safe-output types.
- **Feed URLs:** added all 13 confirmed RSS/Atom URLs inline in the Research section so the agent
  has exact fetch targets. Two exceptions documented:
  - Anthropic: no official RSS — agent must fetch `www.anthropic.com/news` directly.
  - Azure Updates CDN feed (`azurecomcdn.azureedge.net/en-us/updates/feed/`) broken since mid-2024;
    fallback to scraping the updates page noted in the prompt.
- **Network allowlist:** added `feeds.arstechnica.com` (the actual feed subdomain, distinct from
  `arstechnica.com` which serves the HTML site).
